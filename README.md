# Git 与代码版本管理实践
## 实践流程
1.  完成 Git 安装与用户配置，初始化本地仓库。
2.  在 GitHub 创建公开仓库 `git2026`，关联远程地址。
3.  完成3次代码提交并推送到远程仓库。

## 三、提交说明
1.  第1次：创建并提交初始测试代码。
2.  第2次：为代码添加注释
3.  第3次：调整代码格式

## 四、问题与解决
1.  远程地址配置错误：删除错误配置后重新添加正确仓库地址。
2.  分支不匹配：使用 `git push -u origin master` 完成推送。

## 五、学习心得
本次实践掌握了 Git 版本控制的基础操作，理解了版本管理逻辑，提升了问题排查能力，为后续项目开发打下基础。
